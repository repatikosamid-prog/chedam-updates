# chedam-updates

Weekly and monthly updates for the Chedam YouTube series: video scripts, channel artwork and build notes.

The Chedam software itself (specifications, hub scripts, technical docs) lives in the main repository: <https://github.com/repatikosamid-prog/chedam>.

## Layout

| Folder | Contents |
| --- | --- |
| `YouTube/` | Channel banners, watermarks and video scripts |
| `Claude outputs/` | Artwork drafts generated with Claude |
| `Personal Notes/` | Running notes on problems found during the build and how they were handled |

## About Chedam

Chedam is an offline-first business system for small retail stores (POS, inventory, team and back office) that runs on a low-cost hub over the store's own Wi-Fi, with no subscription and no internet dependency.
